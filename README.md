# PIXEL SHIFT

모바일 전용 픽셀풍 3D 착시 퍼즐 게임

## 현재 진행 상태 (1차 단계 완료: STEP 1~6)

- [x] 프로젝트 기본 구조
- [x] Three.js 3D 렌더링 (다크 배경 + 시안 액센트 팔레트)
- [x] 플레이어 이동 (격자 기반, 카메라 상대 방향)
- [x] 모바일 가상 조이스틱 (Pointer Events)
- [x] 카메라 드래그 회전 + 45도 스냅
- [x] 기본 스테이지 1개 (직선 경로, 낙사/클리어 판정)
- [ ] 착시 시스템 (STEP 7 예정)
- [ ] 20개 스테이지 (STEP 8 예정)
- [ ] 튜토리얼 (STEP 9 예정)
- [ ] Express + PostgreSQL + Prisma 백엔드 (STEP 10~11 예정)
- [ ] 회원가입/로그인, 랭킹, 친구 시스템 (STEP 12~16 예정)
- [ ] 보안/검증, Koyeb 배포 (STEP 17~19 예정)

## 로컬 실행

```
npm start
```

기본 포트: `http://localhost:3000`

지금은 정적 파일 서버만 있어서 별도 설치(`npm install`) 없이 바로 실행된다.
Three.js는 CDN(importmap)으로 불러온다. STEP 10에서 Express + Prisma로
서버를 확장할 때 npm 의존성이 추가된다.

## 조작

- 좌하단 원형 영역: 가상 조이스틱 (이동)
- 우측 절반 화면: 드래그하여 카메라 회전 (놓으면 45도 단위로 스냅)
- 우상단: 일시정지 / 리셋 버튼
